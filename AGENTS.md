# XR environment assets

Maintain runtime environment data and its independent packaging here. Shell,
rendering, session management and cross-repository architecture belong in
their owning repositories. Keep existing artwork unchanged unless the user
requests editing. Preserve checksums and identify the projection and colour
space. Do not include local source paths, private thread links or credentials
in public manifests. Local package construction does not establish XR runtime
or headset acceptance, and does not establish artwork redistribution rights.

Use the existing contributor identity and actual Git dates. Packaging and
artwork retain separate license notices. Do not create provenance directories.
